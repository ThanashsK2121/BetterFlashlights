# Better Flashlights (v1.0.1)

A lightweight, highly optimized client-side BepInEx plugin for SPT that completely overhauls tactical weapon flashlights for both the player and bots.

## Features
- **Modern LED Overhaul:** Converts real Kelvin temperatures into accurate light profiles (from warm halogens to ultra-cool white LED beams).
- **Procedural Beam Textures:** Replaces blurry vanilla profiles with a dynamically generated, high-resolution beam cookie with smooth edge fading.
- **Dynamic In-Raid Bot Toggle:** Features a BepInEx configuration button (`Apply to Bots`) to toggle bot modifications On/Off in real-time mid-raid.

## Compatibility
- Formatted and fully compatible with **SPT 4.1.0 up to 4.1.6**.

## Developer / Compilation Info
This repository contains the full source code for transparency and open-source contribution. 
To compile, ensure you reference the required `UnityEngine.dll` and `BepInEx.dll` libraries from your SPT client.
